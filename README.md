# 第 21 届智能车竞赛 STC32 工程

基于 STC32G144K 和逐飞底层库的智能车工程，实现摄像头寻线、赛道元素识别、速度与差速控制、舵机转向及打靶控制。

## 主要功能

- **视觉处理**：MT9V03X 图像采集、边线提取与中线计算。
- **赛道识别**：圆环等赛道元素识别与处理。
- **运动控制**：编码器测速、PID 调速、差速控制与舵机转向。
- **打靶控制**：靶环识别及打靶执行机构控制。
- **调试通信**：无线串口数据输出与打靶调试示例。

## 工程结构

```text
libraries/       逐飞底层库与外设驱动
project/
├── code/        摄像头、视觉及赛道识别
├── user/        主程序与中断处理
└── mdk/         Keil 工程及运动、打靶控制模块
examples/        打靶调试示例
```

## 开发环境

- 主控：STC32G144K
- 视觉与惯性传感器：MT9V03X、IMU660RA
- 工具链：Keil uVision / C251
- 工程入口：`project/mdk/seekfree.uvproj`
